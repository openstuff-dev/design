Added `npm create @openstuff-dev/app`: it asks for a name, a stack (web app and server, web app, or package) and a primary colour, and sets up an Nx workspace with the OpenStuff toolkit, lint, CI, Docker, a licence and agent instructions; @openstuff-dev/nx has generators for apps, servers, packages and components, and `sync` brings older workspaces up to date.
